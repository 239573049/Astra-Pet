控制台改版：四种布局，四套主题

现在的控制台是「左侧导航 + 分组设置卡片」，颜色全部写死在 XAML 里（#1C1C1E、#32AA7D 等），只有深色。下面四个布局方案都只用 TKCode.Arc 0.4.0 里已有的控件，颜色全部改为 Arc 设计令牌，所以浅色和深色、八种强调色都能直接切换。布局和主题可以分开选，用顶部的色板把任意主题套到任意布局上看效果。

样机主题
墨绿延续现在的品牌色 #32AA7D；星夜用 Arc 的 Violet，呼应 Astra（星）；晴空是 Arc Blue；软糖是 Arc Rose。实现时会在「常规」里加一个外观设置：浅色 / 深色 / 跟随系统 + 强调色，用户可以自己换。
方案 A

精修侧栏

保留现在的信息结构和使用习惯，只做"去写死、换控件、理层级"。页头加上外观切换；右键菜单排序从 ↑↓ 按钮改成可拖拽的 ReorderableList；设置分组改用 arc:Card。改动最小、风险最低。

用到的 Arc 控件

  • Card、Switch、Slider、Button
  • ReorderableList（菜单排序）
  • ThemeSwitcher（页头）
  • ScrollArea、Tooltip

适合

  • 老用户不需要重新找设置
  • 想先把主题系统做对，布局以后再说

方案 B

宠物舞台

左边固定一块"宠物卡"：当前角色、状态、最常用的四个开关（显示 / 暂停 / 置顶 / 不移动）和大小滑块，任何页面都能看到；右边用顶部 Tabs 切换设置页。控制台的主角从"设置列表"变成"你的宠物"。

用到的 Arc 控件

  • Tabs、Card、Badge
  • Avatar（角色头像）、Select（切换角色）
  • Switch、Slider、Button

适合

  • 用户打开控制台大多是为了管宠物本身
  • 想让控制台更有"桌宠"的性格

方案 C

概览首页

新增一个"概览"页作为打开时的首页：当前角色、番茄钟、AI 提供商、版本更新、健康提醒各一张卡，每张卡都能直接操作或跳到对应设置页。导航收成图标栏，顶部有搜索框，可以直接搜到某个设置（例如搜"喝水"）。

用到的 Arc 控件

  • Card、Badge、Progress（番茄钟）
  • SearchField（搜设置）
  • Tooltip（图标栏）、Button、Switch

适合

  • 功能越来越多，需要一个总入口
  • 想一眼看到"现在开着什么"

方案 D

紧凑工具窗

窗口收窄到约 560 宽，像一个小工具面板：顶部 SegmentedControl 分成"宠物 / 互动 / 小组件 / 智能体 / 系统"五类，每类里用 Accordion 折叠分组，默认只展开第一组。占屏幕少，适合放在桌宠旁边边调边看。

用到的 Arc 控件

  • SegmentedControl、Accordion
  • Switch、Slider、Button
  • ThemeSwitcher

适合

  • 一边看桌宠一边调大小、速度、透明度
  • 小屏笔记本

怎么选

  1. 选一个布局（A / B / C / D），也可以组合，例如"C 的概览首页 + A 的侧栏"。
  2. 选一个默认主题（墨绿 / 星夜 / 晴空 / 软糖），或者"跟随系统 + 用户自选强调色"。
  3. 样机的配色是按 Arc 设计令牌近似画的，实际效果以 Arc 控件为准。AI 页里的提供商卡片和对话框会一起换成令牌配色。
